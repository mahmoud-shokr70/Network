Overview

The network is built from four facility types that receive inbound volume and dispatch it onward. Each node is identified by a facility code (city prefix + area, e.g. CAI-G1, ALY-A1) and sits in one of three zones. The Gateway (CAI-G1) acts as the central relay: several facilities ship to CAI-G1, and CAI-G1 then sends onward to other hubs. Every facility below is currently marked Confirmed.
